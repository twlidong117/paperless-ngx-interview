## 新名词

- 仓库：保存项目文件和变更历史的地方。
- 派生仓库：在自己的账号下建立、同时保留原项目关联的另一个仓库。GitHub 页面将该操作称为 Fork。
- 分支：同一仓库内的一条代码演进路线。默认分支是进入仓库时首先显示的路线。
- 提交：保存一次文件变更的历史记录。提交标识是定位该记录的唯一编号。
- 写入权限：允许在仓库中保存文件变更的操作资格。

## 面试题与参考答案

**问题一：派生仓库与分支有什么区别？**

派生仓库是独立的另一个仓库，通常归不同账号管理；分支是同一仓库内的代码演进路线。派生仓库本身也可以有多条分支。

**问题二：为什么在自己的派生仓库学习？**

我需要能管理和修改的项目副本，并保存学习记录和独立改进。保留来源关系可以说明代码基础来自哪里。

**问题三：代码已经能在 GitHub 打开，能否说明程序可运行？**

不能。打开代码只验证文件访问；程序运行还需要相关软件、配置和实际启动验证。当前阶段只能说完成了项目准备。
